# Section backdrops (optional)

The site ships original, code-drawn backdrops (candlelit hall, library shelves, arched corridor, tower
window, forest edge) tinted by the house theme. To lay a photograph underneath one, add the file here
(WebP, about 1920 px wide, under 300 KB) and set its path in `assets.backdrops` in `src/lib/assets.ts`,
for example `projects: "/images/backgrounds/library.webp"`.

Only use images you own or have a licence for, and keep the credit the licence asks for. Official Harry
Potter film stills are copyrighted and are not included; do not hotlink images from other sites.
