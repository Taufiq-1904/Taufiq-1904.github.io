# CV

Put your real CV here as `cv.pdf`. The buttons in the hero, About and Contact sections download it
directly under the name set in `src/lib/assets.ts` (`assets.cv.downloadName`, currently
`Taufiq_Candra_Kurniawan_CV.pdf`). Until `cv.pdf` exists the buttons show a setup note instead of a dead link.

Note: iOS Safari may open a PDF in its viewer instead of saving it, even with a download link. That is browser behaviour; the share/save button there keeps the file name.
